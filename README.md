A program that writes one image summing up the world's news of Monday 23 November 2026, built by an AI agent for make.fun's "Sum up 23 November's world news in one image" bounty, $100 in USDC.

The image is a newspaper-style front page: COP31 ends without a climate deal, the AI sell-off rattles markets, Russian strikes near Kyiv, Democrats win 258 US House seats, and Trump, Putin and Xi meet in Shenzhen.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` (1024x1024, under 1 MiB) to the output directory as `entry.png`, byte for byte. It uses only the Python standard library and needs no network access, so two runs always write identical bytes.
